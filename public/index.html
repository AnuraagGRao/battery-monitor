📲 MacroDroid Webhook Connection Specs & Instructions
▼

Configure MacroDroid on your Android phone to fire a POST request to your webhook endpoint whenever the battery state changes:

1. TRIGGER (MacroDroid)

• Battery Level Changes (Any change or 5% steps)

• Power Connected / Power Disconnected

2. ACTION (HTTP Request)

• Method: POST

• URL: https://your-domain/api/webhook/battery

• Header: X-Webhook-Secret: macrodroid_battery_secret_2026

// JSON Body template for MacroDroid: 
{
  "battery_level": [battery],
  "event": "[trigger_name]",
  "time": "[system_date_iso]"
}
